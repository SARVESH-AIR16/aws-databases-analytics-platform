# Database design — target exercises

- Relational: compare RDS engine options and Aurora trade-offs before selecting an engine.
- Availability: distinguish Multi-AZ failover from read scaling/read replicas.
- Connections: understand connection pooling and when RDS Proxy is justified.
- NoSQL: design DynamoDB partition/sort keys around access patterns; compare capacity modes and indexes.
- Cache: identify cacheable reads and invalidation requirements before selecting ElastiCache.
- Migration: document source/target compatibility, schema conversion, validation, and rollback.

Database resources are intentionally not created in the first milestone.
